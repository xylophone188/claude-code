# Claude Code Wiki Purpose

Goal: Understand, navigate, and extend the OpenAI Codex CLI (`claude-code`) codebase.

Key questions this wiki should answer:

- How does the Rust CLI handle `/v1/responses` and tool calls?
- What is the plugin / marketplace architecture and how do hooks work?
- How does the agent loop, subagent system, and context management work?
- How do MCP servers, `AGENTS.md`, and custom instructions integrate?
- What are the build, test, and release workflows?
